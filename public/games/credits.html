Snake Classic

The phone

The handset the game is played on is a photograph by Rainer Knäpper (Wikimedia Commons user Smial), retouched by Multicherry, published under the Free Art License: the original file on Wikimedia Commons. The picture in the game is a derivative of that photograph — background removed, the maker's wordmark and the screen contents taken out so the game can draw its own — and is distributed under the same Free Art License. The licence covers the picture only; the game's code is ours.

The game

The snake's pixel art, the mazes and the rules of play were reconstructed from snake3310 by dobragab (MIT License, © 2016 dobragab), a faithful clone of the year-2000 handset game. The bitmap fonts on the screen are nokia-3310-fonts by Přemysl Janouch (ISC License, © 2013). Both notices travel with the source files that carry the data.

Everything else

The remaining nine games use artwork drawn for them; Dino Jump's sprites are traced from the open-source Chromium project's offline game (BSD-3-Clause).
